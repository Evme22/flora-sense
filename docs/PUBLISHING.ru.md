# Публикация репозитория

[English](PUBLISHING.md) | **Русский**

Этот документ предназначен для автора репозитория. Публичная версия Flora Sense создана **как отдельный репозиторий**, а не как ветка или форк закрытого коммерческого проекта. Историю Git из `diploma-project` переносить нельзя.

## Перед публикацией

1. Проверь содержание README, скриншотов и исходного кода. Убедись, что можно показывать оформление магазина и использованные изображения, а права на публикуемый алгоритм и код принадлежат тебе.
2. Создай **новый пустой публичный репозиторий** `flora-sense` на GitHub. Не добавляй при создании README и `.gitignore`, так как они уже включены в комплект.
3. На Mac распакуй комплект в отдельную папку, не внутри `diploma-project`.
4. Из новой папки `flora-sense` выполни команды:

   ```bash
   git init -b main
   git add README.md README.ru.md .gitignore docs recommender session-reranking
   git status --short
   git commit -m "docs: publish Flora Sense technical showcase"
   git remote add origin https://github.com/Evme22/flora-sense.git
   git push -u origin main
   ```

5. После отправки проверь оба README, четыре скриншота, Python-рекомендатель, JavaScript-модуль и тесты. В списке файлов не должно быть закрытых данных. В подготовленный комплект не включены `.env` и настоящие пользовательские данные.
6. Чтобы выложить видео **без потери качества**, открой вкладку **Releases**, выбери *Draft a new release*, создай тег `demo-2026-11` и прикрепи **оригинальный MOV-файл** с названием `flora-sense-demo.mov`. Затем опубликуй релиз. Ссылка на этот тег уже указана в README.
7. Оставь `Evme22/diploma-project` приватным. Не меняй его видимость на Public.

Если будешь использовать другой аккаунт GitHub или другое название репозитория, сначала обнови ссылки.

Если публичный репозиторий уже создан, **повторять `git init` и создавать новый репозиторий не нужно**. Для последующих изменений используй обычные `git add`, `git commit` и `git push`.
