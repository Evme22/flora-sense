# Офлайн-эксперимент с Learning to Rank

[English](ml-experiments.md) | **Русский**

**Дата эксперимента:** 17 мая 2026 года  
**Модель:** CatBoostRanker (`YetiRankPairwise`)  
**Применение:** офлайн-эксперимент, не используется для ранжирования в пользовательском интерфейсе

## Задача

Я проверяла, сможет ли модель ранжирования, обученная на обратной связи пользователей, превзойти базовый content-based алгоритм подбора букетов.

## Сигналы и разметка

Обучающий конвейер группировал показы букетов по рекомендательным сессиям. Метки релевантности назначались по явным действиям пользователя.

| Метка | Действие |
| ---: | --- |
| 0 | Дизлайк |
| 1 | Лайк |
| 2 | Обсуждение с флористом |
| 3 | Создание индивидуальной заявки |

В рассматриваемом запуске встретились только метки 0 и 1. Показ без явной реакции не считался дизлайком. Позиции без обратной связи не включались в целевые метки для обучения.

Такой подход позволяет не смешивать отсутствие ответа с отрицательной оценкой, но заметно сокращает выборку и ограничивает её репрезентативность.

## Данные и результаты

В сохранённых метаданных эксперимента указано **140 показов-кандидатов**. У **110** не было явной итоговой реакции. Оставшиеся **30 размеченных позиций** относятся к **трём рекомендательным сессиям**.

Разделение выполнялось по сессиям: **две для обучения и одна для проверки**. Благодаря этому одна и та же сессия не попадала одновременно в обучающую и проверочную выборки.

| Метрика | Базовый алгоритм | CatBoostRanker |
| --- | ---: | ---: |
| NDCG@5 | 0.660840 | 0.514771 |
| NDCG@10 | 0.804581 | 0.776201 |
| Hit rate@5 | 1.000000 | 1.000000 |
| MRR@10 | 0.500000 | 0.500000 |

В этом запуске CatBoostRanker не превзошёл базовый алгоритм. При этом проверка проводилась всего на **одной сессии**, поэтому разницу нельзя считать устойчивой оценкой качества или доказательством того, что обучаемая модель будет работать хуже на большем объёме данных. Для пользовательских рекомендаций был оставлен content-based алгоритм.

## Использованные признаки

В обучении учитывались характеристики букетов, ответы анкеты, признаки совпадений между предпочтениями и букетами, исходная позиция в базовом ранжировании, а также сведения о сессии и пакете рекомендаций.

Группировка по сессиям сохранялась и при обучении модели ранжирования.

## Что можно воспроизвести

В репозитории опубликованы [функции расчёта метрик](../recommender/training/metrics.py) и модульные тесты для них.

Исходные данные взаимодействий, полный конвейер извлечения и обучения, а также файлы модели остаются закрытыми. Значения метрик перенесены из сохранённых результатов эксперимента. **Они не пересчитывались на синтетическом демонстрационном каталоге.**

Таким образом, по публичному коду можно проверить работу базового рекомендателя и расчёт метрик, но нельзя независимо воспроизвести первоначальное обучение CatBoostRanker.
